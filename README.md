# Robinson Brothers Plumbing

Website for Robinson Brothers Plumbing in Santa Ana, California.

## Run locally

Prerequisite: Node.js

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.

## Build and deploy

Run `npm run build` and publish the generated `dist` directory to any static web host. The build uses relative asset paths, so it can be served from a domain root or a subdirectory. No runtime server or environment variables are required.

The included `netlify.toml` is optional configuration for Netlify; other hosts can deploy `dist` directly.
